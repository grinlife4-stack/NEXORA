# Mandatory project-entry instructions

Before any work, read this file and the [Ecosystem Master Map](https://github.com/grinlife4-stack/TRADIX/blob/main/docs/ECOSYSTEM_MASTER_MAP.md). Then read this repository's README, NEXORA dossier, decision log, and current status.

NEXORA is an independent product/project, not a department or child of TRADIX. TRADIX is reusable production equipment that may design, build, test, secure, package, and prepare NEXORA; this does not transfer NEXORA's ownership, roadmap, data, accounts, finances, users, or operational decisions to TRADIX. EXVARLI is reusable specialist financial-management equipment; it must preserve NEXORA's separate financial perimeter and must not own or mix NEXORA's funds or ledger with another project.

Keep NEXORA independently operable, exportable, and replaceable from shared services. A shared tool must not become a permanent dependency without explicit approval. Repository placement or source-import workflow does not change NEXORA's independent project boundary.

Before editing, confirm this repository, branch, scope, and the exact NEXORA source/status. If work crosses a boundary, define interfaces, data ownership, permissions, and acceptance responsibilities first. If unclear, stop and report the ambiguity.
